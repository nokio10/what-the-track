# Отчёт по изменениям за 2026-04-03

## Контекст

В течение этой сессии работа шла по четырём большим направлениям:

1. Исправление распознавания коротких слов и предлогов в `WhisperX`-пайплайне.
2. Перестройка логики выбора слова-ответа и сборки вопроса/ответа.
3. Добавление GPU-режима для локальных тестов без поломки CPU-режима.
4. Последовательная отладка lyrics/LRC-кейсов и нормализация списка ссылок на треки.

## Изменённые файлы

- `generator_service.py`
- `game_app.py`
- `Dockerfile`
- `docker-compose.yml`
- `docker-compose.nvidia.yml` — новый файл

## Что изменено в `generator_service.py`

### 1. Исправление коротких слов и предлогов

- Добавлены и использованы утилиты:
  - `count_alpha_words`
  - `count_syllables`
  - `should_keep_word_token`
  - `looks_like_usable_alignment`
  - `collect_lyrics_line_spans`
  - `build_lrc_context_string`
- Короткие слова и служебные части речи перестали выкидываться из:
  - `forced_align_lyrics(...)`
  - `process_audio_with_whisperx(...)`
- Это было сделано так, чтобы предлоги сохранялись для:
  - контекста вопроса
  - line-aware таймингов
  - alignment
  - оценки качества текста

### 2. Улучшение lyrics/LRC-пайплайна

- Логика generation-пайплайна переработана в сторону `lyrics-first`.
- При наличии текстов сначала используются lyrics-based режимы, а `Whisper` остаётся fallback-веткой.
- Для lyrics-треков сравниваются варианты `vocals` и `mix`, затем выбирается лучший.
- Добавлен `choose_best_attempt(...)` для сравнительного выбора попытки по качеству и наличию валидной цели.
- Добавлен `score_word_sequence_quality(...)` для оценки качества таймкодированного текста.
- Улучшен `calculate_timings_from_lrc(...)`:
  - оценка позиции ответа внутри строки теперь идёт по слогам, а не просто по числу слов.
- Улучшены `calculate_timings(...)` и `build_context_string(...)`:
  - корректнее работают в lyrics-режиме
  - учитывают строку ответа
  - умеют fallback при неполной line-разметке

### 3. Исправления вокруг конкретного lyrics/LRC бага со строками в скобках

- Добавлены:
  - `clean_lyrics_line_text(...)`
  - `get_lyrics_line_words(...)`
  - `has_timestamped_lrc(...)`
  - `build_clean_lyrics_context(...)`
  - `estimate_lyrics_answer_start_ms(...)`
  - `find_first_answer_occurrence_in_line(...)`
  - `retarget_parenthetical_occurrence(...)`
  - `get_best_forced_attempt(...)`
- `extract_rhyme_words_from_lyrics(...)` теперь берёт последнее слово из очищенной lyrics-строки без скобочного хвоста.
- Для forced alignment с `LRC` добавлен remap на official lyrics:
  - после forced alignment слова дополнительно прогоняются через `align_words_to_lyrics(...)`
  - это синхронизирует line-структуру с официальным текстом, а не с сырыми LRC-фразами
- Исправлен кейс со строками вида:
  - `Свет остался на моих часах (на моих часах)`
- Добавлены защиты от выбора позднего скобочного повтора как реального ответа.
- Добавлен пересчёт `q_end` по первому фактическому вхождению ответа внутри строки.

### 4. Улучшение algorithm-first выбора слова без LLM

- `no-lyrics` режим переведён на `algorithm-first`.
- `LLM` оставлен только как опциональный fallback через `ENABLE_LLM_SELECTOR`.
- `get_algorithmic_choice(...)` стал детерминированным.
- `random.choice(...)` убран из основного алгоритма выбора.
- Добавлены и усилены эвристики в `score_candidates(...)`:
  - штраф за повтор ответа внутри окна вопроса
  - штраф за повтор рядом с ответом
  - штраф за повторяющиеся строки и хвосты строк
  - штраф за припевные/зацикленные паттерны
  - штраф за очевидные конструкции
  - бонус за редкость, длину, слоговую сложность и более “игровые” слова
- Добавлены вспомогательные функции:
  - `build_candidate_repeat_features(...)`
  - `has_obvious_answer_phrase(...)`

### 5. Исправления для lyrics-скоринга

- `score_lyrics_rhyme_candidates(...)` усилен:
  - добавлены штрафы за повторяющиеся строки
  - добавлены штрафы за повторяющиеся хвосты строк
  - добавлены штрафы за короткие повторные припевные строки
- Это было нужно, чтобы снизить шанс выбора “припевных” слов вроде частых повторов.

### 6. Device/runtime/GPU-конфиг в генераторе

- Добавлены:
  - `env_flag(...)`
  - `env_int(...)`
  - `resolve_runtime_device(...)`
  - `resolve_compute_type(...)`
  - `maybe_release_cuda_memory(...)`
  - `should_release_separator_early(...)`
- Добавлены env-параметры:
  - `ENABLE_LLM_SELECTOR`
  - `RELEASE_SEPARATOR_AFTER_ISOLATION`
  - `WHISPER_THREADS`
  - `WHISPER_BATCH_SIZE`
  - `MDX_BATCH_SIZE`
- `process_audio_with_whisperx(...)` теперь принимает `compute_type` явно.
- Batch size и количество потоков стали настраиваемыми.
- Добавлена ранняя выгрузка separator из памяти/VRAM после изоляции вокала в GPU-режиме.

### 7. Нормализация ссылок на треки

- Добавлены:
  - `YANDEX_URL_RE`
  - `normalize_track_urls(...)`
- Генератор теперь умеет принимать ссылки:
  - через новую строку
  - через пробел
  - через `,`
  - через `;`
  - в смешанном формате
- `/start` теперь:
  - нормализует список ссылок
  - валидирует его
  - возвращает `urls_count`
- `generation_task(...)` тоже дополнительно нормализует список ссылок как страховку.

## Что изменено в `game_app.py`

### 1. Более мягкая проверка ответа игрока

- Добавлены:
  - `levenshtein_distance(...)`
  - `answers_match(...)`
- Проверка ответа перестала быть строго `exact match`.
- Сейчас допускается очень консервативная одна опечатка для достаточно длинных слов.

### 2. Нормализация ввода ссылок перед отправкой в генератор

- Добавлены:
  - `YANDEX_URL_RE`
  - `extract_track_urls(...)`
- В `on_gen_start(...)` список ссылок теперь:
  - извлекается из сырого текста
  - поддерживает вставку не только по строкам
  - отправляется в генератор уже как нормализованный список
- В лог админки теперь выводится:
  - `Треков/ссылок: N`

## Итоговая логика после изменений

### Генерация

- Lyrics-треки:
  - при наличии `LRC` сначала идут через `lyrics-first`
  - forced alignment затем ремапится на official lyrics
  - дальше выбирается слово и строятся line-aware question/answer тайминги
- Lyrics без LRC-таймкодов:
  - сначала `Whisper + lyrics`
  - forced alignment без LRC оставлен как fallback
- No-lyrics треки:
  - работают через `Whisper + algorithm`
  - `LLM` по умолчанию выключен

### Ссылки

- Ссылки можно вставлять как:
  - одна ссылка на строку
  - много ссылок в одном абзаце
  - список через пробелы/запятые/`;`

## Наблюдения по итогам работы

- Основная проблема с предлогами была действительно не только в `Whisper`, а и в постобработке.
- Самый сложный баг дня оказался в том, что `LRC`-структура строки и official lyrics-структура строки расходились, особенно на повторах в скобках.
- Для игры алгоритмический выбор ответа оказался устойчивее и понятнее, чем `LLM`-селектор.

## Ограничения

- Автоматические тесты и `py_compile` локально в этой среде не запускались:
  - в рабочем окружении не было установленного Python runtime
- Проверка делалась по:
  - чтению кода
  - логам локальных прогонов пользователя
  - последовательным точечным исправлениям по реальным трекам
